# Changelog

## 0.0.1 — Native-First Architecture Reset

- Rebuilt the module around native D&D5e Item documents and sourcebook-style navigation.
- New independent Draft store preserving source document and all Advancement data.
- General Level 1–20 editor, with native multi-level advancement visibility.
- Staged Apply for selecting reference/existing classes and parent classes.
- Native Item Grant and Item Choice UUID selection and a full-fidelity native advancement editor.
- New GM Dashboard for all planned content families (initial Class/Subclass only).
- Retained World Compendium grouping, source whitelist and published library; avoids destructive migration of v0.0.4 Drafts.
- Safety: manual publishing, DataModel validation, no gameplay runtime, no automatic GitHub actions.
